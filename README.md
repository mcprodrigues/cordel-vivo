# Cordel Vivo

A searchable archive of Brazilian cordel booklets. Computer vision reads the booklet, deterministic code detects meter and rhyme, and a citation-checked LLM enriches it with themes and characters. Search combines text, poetic form and cover image.

> Work in progress: Phase 0 (Foundation).
